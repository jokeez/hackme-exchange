# Contributor Covenant Code of Conduct (HackMe Spot)

## Our Pledge

We pledge to make participation in the HackMe Spot community a harassment-free
experience for everyone.

## Our Standards

**Positive:** empathy, respectful disagreement, constructive feedback.  
**Unacceptable:** harassment, hate speech, doxxing, spam, phishing, sharing
malware or stolen credentials, posting secrets (JWT, seeds, API keys).

## Security

Do not file public issues for exploitable vulnerabilities. Contact operators via
[hackme.tech/contacts.html](https://hackme.tech/contacts.html). See [SECURITY.md](SECURITY.md).

## Enforcement

Report abuse via [contacts](https://hackme.tech/contacts.html). Maintainers may
remove content or ban accounts that violate this policy.
